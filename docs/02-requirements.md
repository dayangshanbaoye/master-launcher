# 02 · 需求文档

标记说明：**P0** = 骨架，做完即可日用；**P1** = 让引擎真的聪明；**P2** = 护城河。
每条都带验收标准，做完逐条对。

---

## P0 · 骨架

### P0-1 统一对象模型 `Target`

所有可启动的东西——app、快捷方式、联系人、系统设置项——统一为 `Target`。

**验收**：新增一种数据源时，只需实现一个 `TargetSource` 适配器，`Resolver` / `Ranker` / UI 全部不改一行。

### P0-2 索引与拼音匹配

三层拼音索引：全拼、首字母、模糊音（z-zh、c-ch、s-sh、l-n、an-ang、en-eng）。构建期一次性生成，运行期只查表。

**验收**：
- `wxdsh` → 微信读书 排第一
- `weixin` → 微信 排第一
- `dtu` / `ditu` → 高德地图 命中（模糊音 + 全拼）
- `读书` → 微信读书 命中（原文子串）
- 500 条目下单次 query < 8ms，纯 JVM 单测可跑

### P0-3 排序器 `Ranker`

```
score = 0.45·matchQuality + 0.30·frecency + 0.15·context + 0.10·pin
```

- `matchQuality`：精确 > 前缀 > 首字母 > 模糊音 > 子串
- `frecency`：`count / (1 + daysSinceLastUse)`，30 天窗口
- `context`：时段、是否插耳机、是否充电、是否连车载蓝牙（P0 只做时段，其余留接口）

**验收**：权重是常量表，改权重不改逻辑；每条结果可打印出得分构成用于调试。

### P0-4 统一解析入口 `Resolver`

`Query → List<Target>`。三个 Surface 共用。

**验收**：`ui/` 包全局搜索 `sortedBy`、`filter`、`packageName ==` 零命中。

### P0-5 Surface A · Canvas 主屏

时间 + 日期 + 引擎排出的 top-4 条目 + 底部手势提示条。**不放图标网格**。

**验收**：主屏没有任何用户可拖拽、可摆放的元素。

### P0-6 Surface B · Search

- 上滑唤起，`EditText` 自动聚焦，系统输入法弹出
- 结果最多 6 条，每条带匹配原因（"首字母"/"今天 3 次"/"快捷方式"）
- 回车直接打开第一项

**验收**：从主屏上滑到能输入 < 200ms；结果超过 6 条说明排序有问题，不靠滚动解决。

### P0-7 Surface C · Browse（master-detail，纯文字）

左栏分类（引擎生成），右栏条目。**无图标**，条目为文字加边框。

- 分类内按 frecency 排序，不按字母
- 只有"全部"分类挂拼音首字母索引条
- 分类切换用左右滑，不用点
- 同分类下共同前缀的条目（"某某极速版"/"某某HD"），差异部分用次级文本色渲染成后缀

**验收**：左栏 76dp 放得下 3 个中文字；条目行高 44dp，一屏 7–8 项；中英混排字重一致。

### P0-8 手势层

上滑 → Search，下滑 → Browse，四角对角滑 → 4 个自定义槽。

**验收**：识别阈值 48dp / 300ms；`GestureRegistry` 只存 `gestureId → targetId` 映射，不含任何业务逻辑。

### P0-9 分类生成

优先级：`ApplicationInfo.category` → 内置 metadata 映射表 → 首次安装时一次性兜底打标。

**验收**：用户不能创建、重命名、删除分类；分类结果可被用户对单个条目覆盖（长按 → 改分类），覆盖记录持久化。

### P0-10 基础工程

默认 Launcher 接管、图标缓存（Browse 不用但 Canvas/Search 用）、Proto DataStore 索引快照、`PACKAGE_ADDED`/`REMOVED` 增量更新。

**验收**：冷启动到首帧可交互 < 150ms。

## P1 · 让引擎真的聪明

### P1-1 语音输入

搜索框右侧常驻 🎤。**语音是 Search 的输入通道，不是第四个 Surface。**

- 走 `SpeechRecognizer`，**必须用 `onPartialResults` 增量查询**，不能等 `onResults`
- 停顿 600ms 锁定第一项
- 语音出汉字，走 label 精确匹配，不走拼音模糊
- 无 Google 服务的设备预留厂商 SDK 适配接口（讯飞/百度离线包约 30–50MB），接口先定义，实现可后置

**注意**：调不到第三方输入法（如微信输入法）的语音按钮，那属于输入法进程。但只要搜索框是正常 `EditText`，用户唤出的就是自己的默认输入法，其语音键本来就在——这条路径无需开发。

**验收**：说"微信读"时结果已刷新，不等说完。

### P1-2 快捷方式进索引

索引 `LauncherApps.getShortcuts()`——app 自己发布的静态/动态快捷方式。作为默认 Launcher 天然有此权限，无需 `QUERY_ALL_PACKAGES`。

**验收**：搜 `sys` 出"微信 → 扫一扫"并可直达。

### P1-3 手势提议机制

引擎检测到某 target 连续 7 天进 top-3 且未绑定手势 → 浮一次卡片询问。拒绝后 30 天内不再提议同一目标。

**验收**：卡片一次只提议一个绑定；用户不主动进任何界面也能获得手势。

### P1-4 自定义别名

用户搜错一次并最终点开了某项，长按可"记住这个叫法"。别名写入索引，永久生效。

### P1-5 完整 context 信号

耳机、充电、车载蓝牙接入 `Ranker` 的 context 项。

### P1-6 无结果兜底

搜索无命中时，末条给出"在 XX 中搜索"，转投目标 app 的 search intent 或系统浏览器。

## P2 · 护城河

- **P2-1 通知聚合进 Canvas**：只显示可操作的，且必须替换掉 top-4 中的一项，不新增常驻元素
- **P2-2 免打扰**：按标签临时隐藏一整类 app，到点自动恢复
- **P2-3 跨设备索引同步**：纯本地优先，可选开启
- **P2-4 手势速查表**：主屏长按空白处半透明浮现，松手消失
